
Guia Completo – Criação de Anúncios Profissionais com Google VEO 3 Usando Prompts JSON

Introdução

O objetivo deste guia é ensinar como criar vídeos no Google VEO 3 com qualidade cinematográfica usando prompts estruturados no formato JSON. Essa técnica permite obter controle absoluto sobre a geração, garantindo mais precisão, melhor aproveitamento de créditos e resultados comparáveis a produções de alto custo — anúncios que poderiam custar facilmente mais de R$ 100.000 em agências de produção 3D.

Ao final, você será capaz de:
	•	Criar prompts JSON altamente detalhados e personalizáveis
	•	Integrar LLMs (como ChatGPT) para automatizar a construção dos prompts
	•	Utilizar recursos do VEO 3, como frames iniciais/finais e timeline detalhada
	•	Evitar erros comuns e otimizar o uso de créditos

⸻

🔧 Pré-requisitos

Antes de começar, certifique-se de ter:
	•	Conta no Google Labs com acesso ao VEO 3 (recomendado plano com créditos suficientes)
	•	Ferramenta LLM (ex.: ChatGPT, Claude) para ajudar na criação/edição dos prompts JSON
	•	Conhecimento básico de inglês (o prompt principal precisa estar nesse idioma)
	•	Imagens de referência ou logos (caso vá usar branding específico)
	•	Noções básicas de JSON (estrutura de chaves e valores)
	•	Editor de texto ou IDE para manipular o JSON (Visual Studio Code, Sublime Text, etc.)

⸻

Passo a Passo

1. Entender a Diferença entre Prompt Tradicional e Prompt JSON

Ferramentas: VEO 3
	•	Prompt tradicional: descrição contínua, separada por vírgulas ou frases, menos estruturada.
	•	Prompt JSON: formato segmentado em campos específicos (ex.: visual_style, camera_movement, elements, timeline).

Por que JSON é melhor?
	•	A IA processa instruções de forma hierárquica, reduzindo ambiguidades.
	•	Facilita ajustes e personalização.
	•	Melhora a transição de cena, a emoção e a precisão visual.

Exemplo comparativo:
	•	Tradicional: bloco de texto corrido.
	•	JSON: campos organizados, cada detalhe mapeado para um parâmetro específico.

⸻

2. Estrutura Base de um Prompt JSON

Um prompt JSON típico para VEO 3 pode conter:

{
  "visual_style": "Cinematic, photorealistic, 4K",
  "aspect_ratio": "16:9",
  "description": "Large empty Scandinavian room, sunlit, white walls, light wood floor",
  "camera_setup": "Static wide-angle lens shot, no camera movement for 8 seconds",
  "main_subject": "Sealed IKEA box with visible logo",
  "elements": [
    "bed with yellow throw",
    "bedside tables",
    "lamps",
    "wardrobe"
  ],
  "negative_prompts": ["no people", "no text overlay", "no distracting music"],
  "timeline": [
    {
      "start": 0.0,
      "end": 1.0,
      "action": "Box trembles slightly in the center of the room",
      "audio": "Low rumble, echo in empty room"
    },
    {
      "start": 1.0,
      "end": 2.0,
      "action": "Box bursts open with cardboard dust cloud",
      "audio": "Loud pop, ripping cardboard"
    }
  ]
}


⸻

3. Criando seu Primeiro Prompt JSON

Ferramentas: ChatGPT (ou outra LLM), editor de texto.

Etapas:
	1.	Defina tema e produto (ex.: carro, bebida, tecnologia, cenário fictício).
	2.	Escolha estilo visual (cinemático, fotorrealista, minimalista).
	3.	Descreva elementos principais.
	4.	Liste elementos complementares (até 10 para manter a precisão).
	5.	Adicione negative prompts para excluir o que não deseja.
	6.	Crie uma timeline com ações e áudios por segundo.
	7.	Coloque tudo no formato JSON.

⸻

4. Personalizando com LLM

Você pode pegar um prompt base e pedir para uma IA modificá-lo.
Exemplo:
	•	Prompt original: caixa IKEA → alterar para caixa Amazon + produtos mais vendidos.
	•	IA ajusta automaticamente elementos, descrições e cores.

Pro Tip 🚀: sempre manter a estrutura original para não quebrar o padrão de leitura do VEO 3.

⸻

5. Configurações no VEO 3

Opções:
	•	VEO 3 Fast: 5x mais barato, ideal para testes.
	•	VEO 3 Quality: melhor transição e áudio, use apenas após validar no Fast.
	•	Frames Iniciais/Finais: controle criativo total, mas só funciona com VEO 2 Fast (sem áudio).

⚠️ Atenção:
	•	Evite prompts com mais de 50 elementos → perda de precisão.
	•	Transições longas entre frames iniciais e finais exigem muito ajuste.

⸻

6. Integração com Imagens

Você pode:
	•	Usar apenas imagem inicial → resultados mais limpos.
	•	Usar imagem inicial + final → mais controle, mas pode gerar distorções.

Fluxo:
	1.	Suba a imagem no VEO.
	2.	Ajuste o prompt JSON para descrever a transição.
	3.	Gere no modo compatível (VEO 2 Fast para início/fim).

⸻

7. Automação do Processo

Ferramentas que podem ser integradas:
	•	Zapier/Make → automatizar geração de prompts e upload no VEO.
	•	APIs de LLM → criar variações de prompts em massa.
	•	Planilhas Google → armazenar prompts prontos e elementos de cena.

⸻

🚀 Pro Tips
	•	Sempre escreva descrições claras e objetivas em inglês.
	•	Use paleta de cores no JSON para consistência visual.
	•	Adicione referências visuais (--sref) para manter estilo consistente.
	•	Mantenha o número de ações na timeline entre 3 e 5.

⸻

⚠️ Erros Comuns
	•	Exagerar na quantidade de elementos.
	•	Não testar no modo Fast antes do Quality.
	•	Usar traduções ruins no inglês → IA interpreta errado.
	•	Misturar instruções no mesmo campo.

⸻

💰 Custos e Alternativas
	•	VEO 3 Fast: baixo custo (~R$ 0,20 por vídeo curto).
	•	VEO 3 Quality: mais caro, mas resultado superior.
	•	Alternativas: Runway Gen-3, Pika Labs, Luma AI.
