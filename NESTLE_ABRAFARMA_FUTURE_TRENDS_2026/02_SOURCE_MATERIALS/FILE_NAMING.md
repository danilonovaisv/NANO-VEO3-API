# File Naming

## Padrão

```text
NESTLE_FT26_[PLACEMENT]_[BRAND]_[CONTENT]_[R##]_[WIDTHxHEIGHT]_[FPS].mp4
```

## Exemplo

```text
NESTLE_FT26_LED01_CURVO_NUTREN_PROTEIN_LAUNCH_R02_2048x1536_60FPS.mp4
```

## Projetos

```text
NESTLE_FT26_[ASSET_ID]_[SOFTWARE]_[R##].[ext]
```

## Regras

- sem espaços;
- sem acentos;
- usar revisão com dois dígitos;
- não usar `final`, `final2`, `novo`, `aprovado_novo`;
- master aprovado mantém a revisão aprovada;
- backup recebe o mesmo filename.
