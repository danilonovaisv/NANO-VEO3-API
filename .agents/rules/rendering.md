# Media Rendering Guidelines

## Objective
Ensure reproducible, high-performance, and consistent video rendering generated by Veo 3 on the client side.

## Rules
- **Video Player**: Use `react-player` wrapped with client-side hydration checks (SSR safe).
- **No 3D Camera Simulation**: Render media strictly inside responsive flat CSS grid layouts without simulating physical 3D camera controls in the UI.
- **Loading & Skeleton States**: Display clean visual loading states and skeleton loaders while asynchronous Veo 3 generation operations are running (`operation.done === false`).
